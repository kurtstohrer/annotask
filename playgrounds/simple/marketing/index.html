Annotask is a dev-only browser overlay for your running web app. Mark up the UI with pins, arrows, sections, and highlights. A coding agent reads the structured tasks and applies changes back to source over MCP, CLI, or HTTP. Accept or deny in the browser.

How it works

One annotation becomes one structured task. One agent applies the diff. One click to accept.

Annotate

Pin a note, draw an arrow between elements, highlight text, or sketch a section. Each annotation captures the element, its source file, screenshot, and route context.

Agent applies

Your AI coding agent reads the structured task via MCP, CLI, or HTTP. It gets grounded context — source excerpt, design tokens, component props, interaction history — and applies the change to your source file.

Accept or deny

The task moves to review. You see the result in the browser instantly (HMR). Accept to close, or deny with feedback and the agent re-applies.

Annotate

Four annotation tools, each creating a structured task with grounded context. Every annotation captures the selected element, its source file and line, a screenshot, viewport, and route.

Pins & notes

Click any element to drop a numbered pin. Add a description, and the task includes the element's source file, computed styles, and component context.

Arrows

Draw bezier arrows between elements in six colors. Arrows track scroll and resize, and carry both source and target element context in the task.

Drawn sections

Sketch a rectangle over any area. Add a markdown description for new content areas, layout changes, or visual feedback. Draggable and resizable.

Text highlights

Select text to highlight it in six colors. The task includes the highlighted text, the element context, and a prompt field for describing the change.

Design

Inspect live tokens, edit styles in-browser, and browse detected component libraries — all grounded in your actual source code.

Token inspector

View extracted design tokens — colors, typography, spacing, breakpoints — from your CSS custom properties, Tailwind config, or theme files.

Live style editor

Select any element, edit its styles and classes in real time. Changes are tracked as diffs and committed as structured tasks for the agent.

Component catalog

Detected components from your project and libraries with props, usage counts, and real in-repo examples. Search by name, library, or category.

Audit

Accessibility scanning, performance monitoring, and error capture — each finding becomes a one-click fix task with full context.

Accessibility

Local axe-core WCAG scanning with impact severity, affected elements, and one-click task creation. Tab order visualization overlay.

Performance

Web Vitals, DOM/resource/bundle analysis, interaction recording, and performance scoring. Record sessions and scan for findings.

Error monitor

Console error and warning capture with deduplication, stack traces, source mapping, and one-click fix tasks. Bounded memory, no performance cost.

Agent integration

Three ways to connect an AI coding agent. Tasks flow through a structured lifecycle with grounded context at every step.

MCP (Model Context Protocol)

# One command to configure your editor
npx annotask init-mcp --editor=claude

# Works with Claude, Cursor, Zed, VS Code, Windsurf

CLI

# List pending tasks
annotask tasks --status=pending

# Get full task detail
annotask task <id>

# Update status after applying
annotask update-task <id> --status=review

HTTP API

# RESTful API at your dev server
GET  /__annotask/api/tasks
GET  /__annotask/api/tasks/:id
PATCH /__annotask/api/tasks/:id
POST /__annotask/api/screenshots

Works with your stack

Drop in a Vite or Webpack plugin. Annotask auto-detects your framework and injects source-location attributes at build time.

Vue 3 React Svelte SolidJS Astro Plain HTML htmx
Vite Webpack

Install

Add the plugin, start your dev server, open /__annotask/. The agent connects over MCP, CLI, or HTTP.

Vite

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import { annotask } from 'annotask'

export default defineConfig({
  plugins: [vue(), annotask()],
})

Webpack

import { AnnotaskWebpackPlugin } from 'annotask/webpack'

export default {
  plugins: [new AnnotaskWebpackPlugin()],
}

Then wire an agent:

# MCP (Claude, Cursor, Zed, VS Code, Windsurf)
npx annotask init-mcp --editor=claude

# or install the bundled skills
npx annotask init-skills
